# UCS303 Operating Systems Lab Assignments

This repository contains personal assignment submissions for UCS303 (coursework collection). The solutions are grouped by assignment number in the project root.

## What’s inside

- Assignment folders (`Assignment 4` through `Assignment 11`) containing C and C++ implementations.
- Examples include scheduling algorithms, memory allocation strategies, page replacement implementations, and concurrency demos.

## Note

These are personal assignment solutions created for learning and reference. I have checked them carefully, but they may still contain errors—please review and test before relying on them.
